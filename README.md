# Project Starter (Flutter + GetX Navbar)

โปรเจคเริ่มต้น Flutter แบบสะอาด (Clean Starter Template) พร้อมโครงสร้าง Navbar 5 แท็บหลัก

## โครงสร้างโปรเจค (Folder Structure)

```text
projecte/
├── lib/
│   ├── main.dart
│   ├── controllers/
│   │   └── navigation_controller.dart
│   └── pages/
│       ├── main_page.dart
│       ├── home_page.dart
│       ├── search_page.dart
│       ├── my_recipes_page.dart
│       ├── favorite_page.dart
│       └── profile_page.dart
├── test/
│   └── widget_test.dart
├── analysis_options.yaml
├── db.json
├── pubspec.yaml
└── README.md
```

## Navbar Tabs (Bottom Navigation Bar)

1. **หน้าแรก** (`home_page.dart`)
2. **ค้นหา** (`search_page.dart`)
3. **สูตรของฉัน** (`my_recipes_page.dart`)
4. **รายการโปรด** (`favorite_page.dart`)
5. **โปรไฟล์** (`profile_page.dart`)

## วิธีติดตั้งและรันโปรเจค

```bash
flutter pub get
flutter run
```
